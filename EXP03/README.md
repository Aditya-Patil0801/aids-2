# 🎓 Viva Questions & Answers

### 1. What is Fuzzy Logic?
**Answer:**  
Fuzzy Logic is a form of logic that allows values between 0 and 1, enabling reasoning with uncertainty and partial truth.

---

### 2. What is a Fuzzy Set?
**Answer:**  
A fuzzy set is a collection of elements where each element has a degree of membership ranging from 0 to 1.

---

### 3. What is a Membership Function?
**Answer:**  
A Membership Function defines the degree to which an element belongs to a fuzzy set.

---

### 4. What is the range of a Membership Function?
**Answer:**  
The membership value ranges from **0 to 1**.

---

### 5. What is a Zero Membership Function?
**Answer:**  
It assigns a membership value of **0** to all input values.

---

### 6. What is a Constant Membership Function?
**Answer:**  
It assigns the same membership value to every input.

---

### 7. What is a Singleton Membership Function?
**Answer:**  
A Singleton Membership Function has only one point with membership value **1**, while all other points have membership value **0**.

---

### 8. What is a Triangular Membership Function?
**Answer:**  
It is a piecewise linear function represented by three points and forms a triangular shape.

---

### 9. What is a Trapezoidal Membership Function?
**Answer:**  
It is similar to the triangular function but has a flat top representing full membership over a range of values.

---

### 10. What is a Gaussian Membership Function?
**Answer:**  
It is a smooth, bell-shaped membership function based on the Gaussian distribution.

---

### 11. What is the difference between Crisp Logic and Fuzzy Logic?

| Crisp Logic | Fuzzy Logic |
|-------------|-------------|
| Values are only 0 or 1 | Values range from 0 to 1 |
| Exact decision making | Approximate decision making |
| No uncertainty | Handles uncertainty |
