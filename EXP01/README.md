# Experiment 01 - Inferencing with Bayesian Network in Python

## 📌 Aim
To implement a Bayesian Network using the **pgmpy** library and perform probabilistic inference on the **Monty Hall Problem**.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- pgmpy
- NetworkX
- Matplotlib

## 📚 Concepts Covered
- Bayesian Networks
- Directed Acyclic Graph (DAG)
- Conditional Probability Distribution (CPD)
- Variable Elimination
- Probabilistic Inference

## 🚀 Steps Performed
1. Installed the required Python libraries.
2. Imported the necessary modules.
3. Created the Bayesian Network structure.
4. Defined the Conditional Probability Distributions (CPDs).
5. Added CPDs to the network.
6. Validated the model using `check_model()`.
7. Performed probabilistic inference using `VariableElimination`.
8. Visualized the Bayesian Network.

## 📊 Output
- Successfully created and validated the Bayesian Network.
- Performed inference based on given evidence.
- Visualized the network showing dependencies between **Guest**, **Prize**, and **Host**.
